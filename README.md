# Kahve Fincanında Kaybolan Algoritma

## Dünyanın En Kritik Projesi

Bu repository, modern yazılım mühendisliğinin en büyük sorununu çözmek için tasarlanmıştır: **Kodların kahve fincanının içinde kaybolması**.

Her gün binlerce algoritma, bir yudum kahve alırken ekrandan düşüp fincanın dibine batıyor. Bu proje, o kayıp algoritmaları kurtarmak yerine, onlara eşlik etmeyi tercih ediyor.

### Nasıl Çalışır?

```bash
python kahve_simulasyonu.py
```

Program çalıştığında:
- Rastgele bir "algoritma" üretir.
- Onu kahve fincanına düşürür.
- Sonsuz bir çay/kahve molası simülasyonu başlatır.
- Hiçbir şey yapmaz ama çok ciddi görünür.

### Özellikler
- %100 gerçek çalışır (hiçbir şey yapmamak anlamında).
- Abartılı hata mesajları üretir.
- Kahve isteme fonksiyonu entegre.
- Tembellik optimizasyonu (TO) algoritması ile güçlendirildi.

### Katkıda Bulunma
Lütfen katkıda bulunmayın. Bu proje zaten mükemmel. Eğer isterseniz bir kahve ısmarlayın.

### Lisans
Bu kod özgürce kullanılabilir, ama kullanırken mutlaka bir kahve içmelisiniz. Aksi halde algoritma kızar.
